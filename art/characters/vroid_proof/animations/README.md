# Animation editing starts here

Open `animation_workbench.tscn` in Godot, select `AnimationPlayer`, and choose a clip in the Animation panel. Edit and save the shared `prototype_clips.tres` library. Restart the weapon IK demo to inspect the result with weapon placement and IK. Live units use this same library.

Full instructions: [Character Animation Editing Guide](../../../../docs/animation-editing-guide.md).

Keep clip names and bone paths unchanged. The workbench is for editor scrubbing, not F6 playback. It does not preview procedural weapon effects or the extra defeat fall. Do not regenerate the library over manual edits.
