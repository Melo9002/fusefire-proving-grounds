FuseFire replacement.

## Asset record

Copy this section below the table when a row needs more detail.

### `OX-P000` — descriptive role

**Local path:** `research/xcom-local/...`

**Source:** package and exact object, mesh, skeleton, animation, or socket name

**Experiment:** linked experiment note and the single question being answered

**Local preparation:** textures removed/omitted, materials replaced, visible
`XCOM REFERENCE` label applied, scale/orientation changes recorded

**What Pedro must produce:** describe the original FuseFire asset by function,
silhouette, approximate dimensions, articulation, modular boundaries, sockets,
contacts, animation beats, and any body-family variants. Avoid treating the
borrowed asset's appearance as a mandatory art direction.

**Acceptance test:** the observable behavior the FuseFire replacement must pass

**Release-safe fallback:** existing FuseFire asset or primitive used when local
research content is unavailable

**Replacement status:** queued / making / integrated / verified / local copy removed

**Removal check:** confirm the copied file is absent from Git, export presets,
packages, public screenshots, recordings intended for publication, and releases

## Graduation rule

A mechanic may survive after its borrowed placeholder is removed. A release
cannot depend on the borrowed file. Replace the content, switch back to the
FuseFire fallback, or remove the experiment before distributing a build.

The committed [FuseFire original proxy kit](../../../art/research/proxies/README.md)
is the preferred fallback for cross-computer experiments. Because those block
assets are original project content, they do not belong in this borrowed-assets
table.
