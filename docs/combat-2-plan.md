# Milestone 04 — Combat, cover, accuracy and LOS 2.0

Ordered implementation checklist. Status: **steps 1–3 complete: baseline audited and corrected, rules defined, controlled examples built**. The running game's accuracy formula and damage balance remain unchanged. See the [editable range and focused checks](combat-controlled-examples.md), [intended Combat 2.0 rules](combat-2-rules.md), [current-rules sheet](combat-current-rules.md), original [ranked audit](quality/combat-audit-2026-11-15.md) and [fix verification](quality/combat-consistency-fixes-2026-11-16.md). Next: step 4, geometry and LOS. Builds on existing actions/archetypes and Generation 2 content. Focused regressions accompany each behavioral change; the final step broadens verification and closes the milestone.

The existing CombatRules evaluation and TacticalActionService query/commit path are the foundation. Ordinary and predicted-cell attack evaluation already exist. Current accuracy applies a 50-point penalty to either half or full cover, combines cover/visibility penalties using their maximum, then applies bonuses and clamps the result. These are prototype contracts to audit, not assumptions that every difference is a bug.

## Completion boundary

Owner's tuning direction, recorded 2026-11-16: high ground should improve accuracy and low ground reduce it; increasing range should start with a gentle penalty and become sharply harder at longer distances; Aim and other abilities should provide substantial accuracy recovery in difficult circumstances. The [step-2 decision sheet](combat-2-rules.md) now specifies provisional numbers, a 100% clear-shot plateau followed by steep range falloff, continuous height, chance-color bands and acceptance examples. They remain pending implementation and tuning. Use a small shared editable tuning resource, a visible calculation breakdown and explicit replay compatibility validation. These future balance changes are not part of the three consistency fixes.

Milestone 04 closes when combat rules and predictions are consistent, positioning has understandable consequences, and the player can inspect those consequences before committing. An identical actor/target/state/action context must produce the same legality for UI and AI. Reaction-specific costs/modifiers remain explicit rather than being mistaken for divergence.

Criticals are optional. Destructible cover requires an investigation and scope decision, not a full destruction simulator. Cover-pose/procedural animation can follow later; it must reflect these authoritative rules. Preserve the ordinary asset-placement workflow while fixing demonstrated tactical geometry mismatches.
