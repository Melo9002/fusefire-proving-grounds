# Phase 1, Task 1.4 — Road Orientation and Connector Agreement

## Result

The source-orientation corrections already present in production revision `cce128b` are correct. Task 1.4 retained that normalization, expanded the permanent geometry regression into a connected road fixture, and added a clean imported-asset capture. Presented world bounds confirm that every supported road surface already resolves to the established Y `0.11` pavement-top contract despite using different anchor modes and metadata offsets.

No road connector, tactical cell, calibration value, or imported GLB changed in this task.

## Imported road audit

The audit loads each actual GLB, resolves imported node transforms, identifies its highest horizontal pavement triangles, and samples all four physical boundaries for bounded carriageway gaps. This distinguishes openings from outer curb strips and avoids the square-AABB ambiguity that concealed F1.

All four module rotations are supported and verified. The crossroad is rotationally symmetric, so it proves opening completeness but cannot reveal yaw sign by itself; the straight, T, and curve provide asymmetric evidence.

## Normalization boundary

`EnvironmentModuleDefinition` visual entries own asset-local `yaw_quarters`. This converts the source mesh into the module's authored local frame exactly once. `EnvironmentModulePlacement.rotation` is then applied through `placement_yaw_radians()` by the production presenter.

This keeps three concerns separate:

1. imported source orientation;
2. authored module connectors and local placement;
3. world-space module rotation.

The semantic profile records the straight asset's physical X traffic axis, but metadata is not the test oracle. Calibration yaw remains untouched. Tactical connectivity remains the authored connector contract and `MapData` remains authoritative.

## Phase 2 visual issues

The first close view suggested a possible 0.10-unit step because straight surfaces use offset `0.11`, while T, cross, and curve use `0.01`. A real presented-bounds assertion disproved that metadata-level interpretation: straight uses a top-center anchor, while the other meshes use their floor anchor and have 0.10-unit height. Both conventions resolve to the same world pavement top at Y `0.11`. A trial that made the offsets identical correctly failed the new assertion by raising T, cross, and curve to Y `0.21`; it was reverted before final verification.

One surface-policy defect remains visible: the kit's white curb/sidewalk boundaries overlap or terminate abruptly where the 20×20 curve meets square modules. The carriageway opening and height are connected, but the curb transition is not yet a certified streetscape seam.

This is recorded rather than concealed with the presenter's optional derived road layer. Phase 2 should certify curb/sidewalk transitions and decide whether kit variants or purpose-built authored assemblies own each seam.
