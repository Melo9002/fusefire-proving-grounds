# Generation 2.0, Task 2.2 — Asset-First Road Presentation

## Result

The certified reference slice now names and enforces imported-asset ownership of normal visible roads. `GeneratedTerrainPresenter` explicitly selects `RoadPresentationMode.ASSET_FIRST`. Procedural asphalt, sidewalk, curb, and marking boxes remain available only through `RoadPresentationMode.DERIVED_DIAGNOSTIC` and cannot appear through the default production path.

The underlying F8 suppression was already present in revision `cce128b`. Task 2.2 consolidates it into an explicit presentation contract, verifies the actual generated-terrain entry path, measures the former overlap, refreshes rendered evidence, and corrects stale documentation that still claimed derived geometry lived underneath imported roads.

## Rendering-path audit

### Normal modular environment path

1. `GeneratedTerrainPresenter.build()` handles authoritative generated structures and tactical cover presentation as before.
2. Maps containing environment modules dispatch explicitly to `ModularEnvironmentPresenter` with `ASSET_FIRST`.
3. Each supported road module resolves one semantically approved City Roads asset through its catalog visual.
4. Calibration, asset-local corrective yaw, canonical module rotation, anchor placement, and the 2× horizontal module adapter produce the final visible surface.
5. `_add_ground_marker()` deliberately skips road and intersection modules, so it does not add a generic floor underneath them.
6. `_add_road_streetscape()` is not called in asset-first mode.

### Explicit diagnostic path

`DERIVED_DIAGNOSTIC` adds a `RoadStreetscape` child for each supported straight, T, or cross module while retaining the imported mesh for comparison. It creates:

| Surface | Generated height | Normal status | Purpose |
| --- | ---: | --- | --- |
| Asphalt | 0.035 | suppressed | visualize authored carriageway regions |
| Sidewalk | 0.10 | suppressed | visualize the two-cell pedestrian contract |
| Curb | 0.16 | suppressed | visualize carriageway boundaries |
| Marking | top 0.047 | suppressed | visualize authored lane-marking regions |

The imported pavement top resolves to world Y `0.11`. Diagnostic curbs therefore protrude to `0.16` and would create a visible 0.05-unit conflict if enabled normally. Asphalt, sidewalk, and marking boxes also occupy regions already supplied by the imported mesh. They are useful spatial diagnostics, not missing production surfaces.

The curve module has no procedural `surface_sections()` fallback. Its visible geometry is always the measured imported curve asset.

## Production change

`ModularEnvironmentPresenter` replaces its boolean road flag with a small named enum:

- `ASSET_FIRST` — default normal presentation; only imported road visuals own supported surfaces.
- `DERIVED_DIAGNOSTIC` — explicit developer comparison mode; adds reconstructed boxes and identifies the mode on the presentation root.

`GeneratedTerrainPresenter` passes `ASSET_FIRST` explicitly rather than relying on a default. This makes the certified path reviewable at the integration boundary and avoids treating an unnamed boolean as a durable rendering policy.

No imported asset, calibration, road connector, tactical footprint, traversal rule, cover rule, line-of-sight rule, parcel recipe, building, or street-furniture placement changed.

## Surface disposition

### Normal presentation

- **Retained:** reviewed imported straight, T, cross, and curve meshes; their own pavement, sidewalks, curbs, and markings.
- **Suppressed:** all `RoadStreetscape` asphalt, sidewalk, curb, and marking boxes.
- **Absent by contract:** generic module ground markers for roads and intersections.
- **Retained independently:** tactical `MapData`, connectors, walkability, and explicit road obstacles.

### Diagnostic presentation

- Imported meshes remain visible as the comparison target.
- Derived cross-section boxes are retained intentionally and labeled by the root's `derived_diagnostic` mode metadata.
- This mode is explicit-only in tests and tooling; `GeneratedTerrainPresenter` never selects it for normal play.
